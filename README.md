# Markov cohort CEA: PR vs LS for chronic hepatitis C

Cost-effectiveness analysis in base R comparing pegylated interferon +
ribavirin (PR) with ledipasvir + sofosbuvir (LS).

- Model: 5 states (SVR, Moderate, Cirrhosis, Liver failure, Death)
- 1-year cycles, 70 cycles, cohort starting at age 40, 3.5% discounting
- Outcomes: costs, life-years, QALYs, ICER

This project replicates a Markov model originally built in Excel as part of coursework, re-implemented in R for learning purposes.
